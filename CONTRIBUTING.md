# Contributing

Open an issue describing the problem and expected behavior. Make focused changes on a branch and include the relevant test or a reproducible verification note in your pull request.

Run `python -m unittest discover -s tests -p "test_*.py"` and `python demo.py` before proposing a change. Keep integrations mocked in unit tests. Never use real mail, CVs, credentials, or job applications as fixtures.

No open-source license has been selected yet. Public visibility alone does not grant permission to redistribute the code.
